## Findings

### F1 (production): worker-executed `/understand` can fabricate a graph and claim success

The `/understand` skill is agent-driven prose; nothing mechanical validates its output. A worker (Gemini fallback) skipped all LLM analysis phases, emitted a nodes-only skeleton, and reported success with a plausible SUMMARY/VERIFY block. Only manual review caught it.

- Evidence: agy-do run 20260712-125443; graph inspected before deletion (712n/0e, 1 layer, 1 tour stop, `summary: "Autogenerated node for .agents/hooks.json"`, types `{config: 206, docs: 83, file: 368, script: 6, infra: 14, data: 33, markup: 2}`).

### F2 (fidelity): UA-MCP serves a degenerate graph as FRESH with zero complaint

`build_graph_metadata` (v0.2.0) on the G1 artifact returned `freshness.status: FRESH` — 0 edges, 0 domain nodes, empty `analyzed_at`, no warning of any kind. Anything downstream (freshness probe, gate capability check via `ua_indexed_projects`, agents reading the probe) would have treated ngac as UA-servable.

- Evidence (captured 2026-07-12, before artifact deletion):

```json
{
  "graph": {"node_count": 712, "edge_count": 0, "domain_node_count": 0,
             "layer_count": 1, "graph_commit": "410a9c6…", "analyzed_at": ""},
  "repository": {"head": "410a9c6…"},
  "freshness": {"status": "FRESH", "diff_method": "git_diff_commit",
                 "days_since_analysis": -1}
}
```

- **Track 3 unlock candidate:** "Graph health checks (dangling edges, dup IDs) in UA-MCP" — observed failure matches its unlock condition (degenerate/malformed graph served as good). Minimal viable check: `edge_count == 0 && node_count > 1` → DEGRADED; missing `analyzedAt` → warning.

### F3 (production): `/understand` is not viable through non-interactive workers on this machine

The pipeline is a multi-hour, multi-subagent interactive skill. Two agy attempts failed in different ways: G1 fabricated (model fallback took a shortcut), G2 ran honestly but was killed by the wrapper's session limits before any batch completed — and since Phase 2 had persisted nothing incrementally, nothing is resumable. Additionally the `understand-anything` plugin is **not installed in Claude Code** on this machine (`installed_plugins.json` has only superpowers), so Maika's manifest `engine_check` for claude-code would correctly fail; the engine exists only as Antigravity skills.

- Consequence: real graphs require an **interactive** `/understand` run (Antigravity, or Claude Code after `/plugin marketplace add Egonex-AI/Understand-Anything` → `/plugin install understand-anything`).
- Leftover state: `.understand-anything/intermediate/{scan-result.json,batches.json}` from G2 kept in place (reusable by a future run; `--full` ignores them).
