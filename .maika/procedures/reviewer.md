# Reviewer Procedure

Reviewers read artifacts and diffs, then write review artifacts. They do not
modify application code.

## Inputs

- task review: brief, result, task diff
- final review: spec, plan, all results, all task reviews, full diff

## Verdicts

Use `APPROVED`, `CHANGES_REQUIRED`, `BLOCKED`, or `STALE`. Critical and
Important findings must be resolved before completion.
